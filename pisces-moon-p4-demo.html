PISCES MOON P4
An operating system for the ELECROW CrowPanel Advanced 7" — $46 of hardware running a dual RISC-V at 360MHz with a dedicated ESP32-C6 coprocessor. 56 apps across 7 categories. The Ghost Engine runs on the C6 — dedicated silicon, not a software trick.
C6 GHOST ENGINE
The ESP32-C6 coprocessor does nothing but radios. WiFi scan, BLE scan, 802.11 promiscuous capture, EAPOL collection, NFC — all on dedicated silicon. The P4 can play Doom; the C6 never stops wardriving.
MODULAR PEER REGISTRY
Apps don't ask "does this board have LoRa?" They ask "is a LoRa peer available?" Plug in an SX1262 slot module → it registers. Plug in a T-Beam Supreme S3 → secondary WiFi/BLE/LoRa appears. Unplug anything → capability withdraws. No reboots.
BRIDGE MODE
Connect a T-Deck Plus, Cardputer ADV, or T-Beam Supreme S3 running Pisces Bridge firmware via USB. Live detections replace demo data. The P4 demo becomes a real intelligence dashboard. Web Serial API — Chrome/Edge only.
NAVIGATION
Tap any category to open it. Tap an app to launch it. Tap the green topbar to go back. Same navigation model as the real device.
